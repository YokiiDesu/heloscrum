# Conversation Style

Project settings → Conversation offers Concise, Conversational and Expressive. Conversational is the default. The choice is saved per project with an optimistic revision check.

New sessions receive the writing guidance in their initial brief. Existing sessions receive the current choice with the next naturally delivered message batch. Changing the setting does not wake agents, run an extra model, rewrite historical chats or alter task/review authority. The exact applied style is recorded with the delivery envelope so history normalization preserves the original sender and message body.

All styles retain specific evidence, task references, uncertainty and unrun checks. Expressive permits warmth, humor and encouragement, but does not request fictional lived experiences, emotions, results, or banter-only wakeups. User instructions still govern the work.

Example: “Good catch. The filter now survives reload; could you recheck this candidate?” The candidate reference and evidence still belong in the actual review record.
