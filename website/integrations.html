A server on another computer needs a reachable address. “Localhost” always means the machine running HeloScrum’s backend.

☁

Amazon Bedrock & SageMaker AI

Use AWS profiles with supported Bedrock models or compatible SageMaker inference endpoints.

Agent use requires compatible tool calling. A SageMaker deployment must accept the request format HeloScrum’s adapter sends.

Models accessed through endpoints do not inherit another provider app’s skills or conversation history. Worktrees and execution remain on the HeloScrum backend machine.
